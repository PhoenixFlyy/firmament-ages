# Firmament Ages installieren

Du brauchst nur Prism Launcher und einen Minecraft-Account (Java Edition). Mods, Configs und Updates holt die Instanz bei jedem Start selbst.

1. **Prism Launcher installieren:** https://prismlauncher.org/download (Version 11 oder neuer).
2. **Mit Microsoft anmelden:** in Prism oben rechts *Accounts → Manage Accounts → Add Microsoft*, im Browser einloggen.
3. **Java automatisch laden lassen:** *Settings → Java* öffnen und *Auto-detect Java* sowie *Auto-download Java* einschalten (Minecraft 1.21.1 braucht Java 21).
4. **Instanz importieren:** *Add Instance → Import* wählen, diese Datei `FirmamentAges-Prism.zip` auswählen, *OK*. Nicht entpacken. Es erscheint die Instanz **Firmament Ages**.
5. **Arbeitsspeicher prüfen:** Rechtsklick auf die Instanz → *Edit → Settings → Java*. Eingestellt sind 8 GB Maximum. Hat Dein PC nur 16 GB RAM, lass es dabei; mit weniger als 16 GB wird es eng.
6. **Starten:** Doppelklick auf **Firmament Ages**. Vor dem Spiel öffnet sich ein kleines packwiz-Fenster und lädt rund 400 Dateien (beim ersten Mal einige Minuten). Danach im Multiplayer den Server hinzufügen, dessen Adresse Du von Felix bekommst.

Updates: Bei jedem Start lädt das packwiz-Fenster den neuen Stand. Du musst nichts tun. Falls es beim Start einen Fehler meldet, schick Felix einen Screenshot und die Datei `minecraft/logs/latest.log` aus dem Instanz-Ordner (Rechtsklick → *Folder*).
