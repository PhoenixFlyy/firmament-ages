# Textures, second pass (2026-10-01)

Everything here is generated by `python dev/gen_textures.py` (rerun after any change; `--check` validates). Items live
under `kubejs/assets/firmages/textures/item/`, blocks under
`mod/firmages-core/src/main/resources/assets/firmages/textures/block/`. Contact sheets (not tracked):
`dev/shrine-viewer/out/textures_sheet.png` (items and blocks, animated ones as frame rows) and
`dev/shrine-viewer/out/consecrated_sheet.png` (every consecrated role with accent 0..8 composited).

## Animated textures

| Texture | Frames | Frametime | Motion |
|---|---|---|---|
| `item/arcane_keystone` | 4 | 12, interpolated | the carved rune breathes between two rune tones (subtle) |
| `item/awakened_keystone` | 4 | 8, interpolated | the fissure pulses white to violet, sparks change place |
| `item/humming_core` | 4 | 3 | the current runs along both coil bands, the bolt pulses |
| `item/data_matrix` | 8 | 3 | the glyph grid scrolls up one row per frame, one bright cursor row |
| `item/star_chart` | 4 | 8, interpolated | eight stars twinkle with different phases |
| `item/quantum_core` | 8 | 2 | a white spark orbits the cyan ring with a fading trail |
| `item/ultimate_singularity` | 8 | 3, interpolated | the violet event horizon rotates, the four rays blink |
| `block/shrine_heart_top_lit` | 4 | 6, interpolated | coals and cracks glow (unchanged from the first pass) |
| `block/origin_altar_top` | 6 | 4, interpolated | the eye pulses to white, the inner ring turns, corner glyphs breathe |

KubeJS builds the `item/generated` model for the items; the atlas stitcher picks the `.mcmeta` up on its own, no
model change needed. The block `.mcmeta` sits in the mod jar next to the PNG.

## Consecrated family (naming contract)

Blocks `firmages:consecrated_<role>`, roles `stone`, `brick`, `pillar`, `lamp`, `metal`, `glass`, `trim`, `scaffold`.
Every block has the blockstate property `accent=0..8` (the ring / Age index); `lamp` also has `lit`. All roles are
one material: pale sky-marble (`PAL["marble"]`), faint gold veins (`PAL["vein"]`).

Base textures (16x16, static):

| Role | Textures | Render type | Notes |
|---|---|---|---|
| stone | `consecrated_stone` | solid | smooth marble, two veins, soft bevel |
| brick | `consecrated_brick` | solid | 8x4 marble bricks, pale mortar, veins on two bricks |
| pillar | `consecrated_pillar_top`, `consecrated_pillar_side` | solid | top: gold ring inlay; side: four flutes, gold fillet at rows 0 and 15 (stacked pillars show a 2 px gold band). Use `top` for up/down, `side` for the four sides, like `minecraft:block/cube_column` |
| lamp | `consecrated_lamp` (unlit), `consecrated_lamp_lit` | solid | marble frame, gold lattice, dim violet glass / warm glow. Give the lit state `light_emission 15` in the block, the texture itself is not emissive |
| metal | `consecrated_metal` | solid | marble plate with a gold frame, four rivets, centre bar |
| glass | `consecrated_glass` | `minecraft:translucent` | 1 px marble frame, inner alpha 56, one faint vein, corner gleam |
| trim | `consecrated_trim` | solid | marble with a horizontal gold moulding (rows 5..10) |
| scaffold | `consecrated_scaffold` | `minecraft:cutout` | 2 px marble frame, X brace, transparent holes |

Accent overlays `consecrated_accent_<N>.png`, N = 0..8: corner brackets, mid-edge ticks and one 5x5 rune per Age in
ring N's `response.beam_color` (read from `data/firmages/firmages_shrine/tier/ring_N.json` at generation time), with
a 1 px dark halo at alpha 120 so the pale Ages (4 Industrial `#F0F0F0`, 7 Space `#E0E8FF`) still read on the marble.
Transparent elsewhere; the same nine files composite over every base, including glass and scaffold.

### Model layout (recommended: multipart, one overlay model set shared by all roles)

One base model per role (two for the lamp), nine accent overlay models shared by every role. Multipart stacks the
overlay on the base; the overlay faces are coplanar with the base faces, which is the vanilla grass-block pattern
(depth test LEQUAL, no z-fighting).

`blockstates/consecrated_lamp.json`:

```json
{
  "multipart": [
    { "when": { "lit": "false" }, "apply": { "model": "firmages:block/consecrated_lamp" } },
    { "when": { "lit": "true" },  "apply": { "model": "firmages:block/consecrated_lamp_lit" } },
    { "when": { "accent": "0" }, "apply": { "model": "firmages:block/consecrated_accent_0" } },
    { "when": { "accent": "1" }, "apply": { "model": "firmages:block/consecrated_accent_1" } },
    { "when": { "accent": "2" }, "apply": { "model": "firmages:block/consecrated_accent_2" } },
    { "when": { "accent": "3" }, "apply": { "model": "firmages:block/consecrated_accent_3" } },
    { "when": { "accent": "4" }, "apply": { "model": "firmages:block/consecrated_accent_4" } },
    { "when": { "accent": "5" }, "apply": { "model": "firmages:block/consecrated_accent_5" } },
    { "when": { "accent": "6" }, "apply": { "model": "firmages:block/consecrated_accent_6" } },
    { "when": { "accent": "7" }, "apply": { "model": "firmages:block/consecrated_accent_7" } },
    { "when": { "accent": "8" }, "apply": { "model": "firmages:block/consecrated_accent_8" } }
  ]
}
```

For the other roles drop the two `lit` parts and apply the base model unconditionally
(`{ "apply": { "model": "firmages:block/consecrated_stone" } }` as the first part).

`models/block/consecrated_lamp.json` (and `consecrated_lamp_lit.json` with `consecrated_lamp_lit`):

```json
{
  "parent": "minecraft:block/cube_all",
  "textures": { "all": "firmages:block/consecrated_lamp" }
}
```

Pillar: `"parent": "minecraft:block/cube_column"`, `"end": "firmages:block/consecrated_pillar_top"`,
`"side": "firmages:block/consecrated_pillar_side"`. Glass: `cube_all` plus `"render_type": "minecraft:translucent"`.
Scaffold: `cube_all` plus `"render_type": "minecraft:cutout"`.

`models/block/consecrated_accent_0.json` (1..8 identical except the texture):

```json
{
  "render_type": "minecraft:cutout",
  "ambientocclusion": false,
  "textures": { "accent": "firmages:block/consecrated_accent_0", "particle": "firmages:block/consecrated_accent_0" },
  "elements": [
    {
      "from": [0, 0, 0],
      "to": [16, 16, 16],
      "neoforge_data": { "block_light": 15, "sky_light": 15, "ambient_occlusion": false },
      "faces": {
        "down":  { "texture": "#accent", "cullface": "down" },
        "up":    { "texture": "#accent", "cullface": "up" },
        "north": { "texture": "#accent", "cullface": "north" },
        "south": { "texture": "#accent", "cullface": "south" },
        "west":  { "texture": "#accent", "cullface": "west" },
        "east":  { "texture": "#accent", "cullface": "east" }
      }
    }
  ]
}
```

`neoforge_data.block_light`/`sky_light` 15 makes the overlay full-bright (emissive-ish) without touching the block's
light level; drop it if the consecrated ring should only glow where it is lit. The multipart `particle` texture comes
from the first applied model, so the base model's particle wins. Item models: `models/item/consecrated_<role>.json`
with `"parent": "firmages:block/consecrated_<role>"` (lamp: the lit model), no accent in the inventory.

If one model per (role, accent) is preferred instead of multipart, put the overlay as a second element with identical
`from`/`to` into the base model and set the model's `render_type` to `cutout` (the base faces then render in the cutout
layer too, which is fine for opaque textures); glass then needs `translucent` for both.

### Checker

The mod ships these models (firmages-core 0.6.0). `gen_textures.py --check` reports every consecrated texture that no
mod model references as an error, plus missing models and textures. Every `.mcmeta` and model JSON must be LF; the
generator writes LF on Windows too (`write_json`).
