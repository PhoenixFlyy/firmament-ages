# Firmament Ages

A co-op progression modpack for Minecraft 1.21.1 (NeoForge) in a TerraFirmaCraft world.
Everyone on a server lives in the same Age, from knapped flint in Dawn to a draconic reactor and a Stargate.
Each Age ends with an offering at one shared shrine, and the sky opens the next.

## Play

- **CurseForge App:** search for *Firmament Ages* and install. Give the game 8 GB of RAM (*Settings → Minecraft → Java Settings*).
- **packwiz** (Prism Launcher, MultiMC): pre-launch command `"$INST_JAVA" -jar packwiz-installer-bootstrap.jar https://raw.githubusercontent.com/PhoenixFlyy/firmament-ages/main/pack.toml`.
- **Stuck?** The [walkthrough](docs/WALKTHROUGH.md) goes through every Age.

## Server

Every release on CurseForge carries a server pack as an additional file; its `README-SERVERPACK.md` explains the start. 8 GB of heap for up to four players, 10 GB for five to ten.

Bugs: [issue tracker](https://github.com/PhoenixFlyy/firmament-ages/issues). Changes: [`CHANGELOG.md`](CHANGELOG.md).
